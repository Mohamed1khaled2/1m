# رحلة المليون

موقع شخصي: **محمد قرر يجمع مليون جنيه في 2027**، وبيسجّل كل اللي بيعمله أول بأول، والناس بتتفرج وتتابع.
مفيش حسابات للزوار ولا أي داتا منهم.

- **الصفحة الرئيسية `/`**: الرقم لحد دلوقتي، وسلّم المليون (درجة كل ٢٠٠ ألف)، والعدّاد، والخطة على صفحة دفتر، واليوميات، وصناديق الأرباع.
- **الأدمن `/admin`**: بكلمة سر. منها بتكتب اليوميات (خطوة / فلوس دخلت / وقعة / درس، ومعاها لينك الفيديو) وبتعدّل الخطة. أي حاجة تنشرها بتظهر على طول.
- **صورة المعاينة**: لما حد يشارك اللينك بتظهر باسمك ورقمك الحالي.

## التشغيل

1. **Supabase**: افتح SQL Editor ونفّذ [supabase/schema.sql](supabase/schema.sql).
2. انسخ `.env.example` لـ `.env.local` واملاه.
3. صورتك في `public/creator.jpg` (مربعة)، وكلامك في [src/lib/creator.ts](src/lib/creator.ts).
4. `npm run dev`، وبعدين ادخل `/admin`.
